Realistic Card Faces — dummy

Bank logos are fetched live from the internet (Clearbit logo API, by bank domain). The rest — brand gradient, EMV chip, contactless, embossed number, network mark, name, valid-thru — is rendered. Network marks shown as styled stand-ins. Data is your real cards.

If a bank logo box shows text instead of an image, the logo fetch was blocked/offline — the app would fall back to the bank name exactly like that. No real card photo is used (not fetchable by last4); this is a generated face with the real logo on it.

  • What's fetched from the internet: the bank logo only (Clearbit logo API → logo.clearbit.com/axisbank.com, idfcfirstbank.com). Mapped from the SMS bank name. Cached after first load; falls back to the bank name if offline.
  • Network mark (VISA / Mastercard / RuPay): bundled vector assets, picked from BIN/SMS if known, else a neutral chip-only face.
  • Everything else is generated with brand-accurate gradients + EMV chip + contactless + embossed •••• last4 + holder name + valid-thru (from statement if available, else hidden).
  • No real card photo — not reliably fetchable by last4 and copyrighted. This generated face is the realistic, safe alternative.
